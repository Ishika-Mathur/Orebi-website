# Orebi E-Commerce Website 🛍️

## About the Project

Orebi is an e-commerce website developed using React.js, JavaScript, Redux Toolkit, Bootstrap, and CSS. The main aim of this project is to create a simple and user-friendly online shopping website with a clean design and easy navigation.

While building this project, I learned how to create reusable React components, manage application state, and design a responsive website.

## Features

- Simple and user-friendly interface
- Product listing and browsing
- Product details page
- Login page interface
- Responsive website design
- Reusable React components
- State management using Redux Toolkit
- Styling using Bootstrap and CSS

## Technologies Used

- **React.js** – To build the user interface.
- **JavaScript** – To add functionality and interactivity.
- **Redux Toolkit** – To manage application state.
- **Bootstrap** – To create layouts and style components.
- **CSS** – To customize the website design.
- **Git and GitHub** – To manage and store the project code.

## Installation and Setup

Follow these steps to run the project on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/Ishika-Mathur/Orebi-website.git
```

### 2. Open the project folder

```bash
cd Orebi-website
```

### 3. Install the dependencies

```bash
npm install
```

### 4. Run the project

```bash
npm start
```

After running the command, open the local URL shown in your terminal to view the website.
