# Orebi Website

A modern and responsive e-commerce website built using React.

## Features
- Product Listing
- Product Details Page
- User Login
- Responsive Design
- Redux Toolkit State Management

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- Bootstrap
- CSS

## Installation

1. Clone the repository
2. Install dependencies

npm install

3. Run the project

npm start
